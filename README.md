# CAS Compass

Public Swift package for the reusable Creative App Solutions compass control.

## Requirements

- Xcode 26 or later
- Swift 6
- iOS 26 or later
- Mac Catalyst 26 or later

## Add to an Xcode project

In Xcode, choose **File > Add Package Dependencies**, enter the public repository URL below, select version `1.1.1` or later, and add the `CASCompass` library product to the required application targets.

```text
https://github.com/KMessina1/CAS-Compass.git
```

```swift
import CASCompass
```

No GitHub account or private-repository authentication is required to download this public package.
